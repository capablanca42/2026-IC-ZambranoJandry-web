# Sistema Web Helpdesk con Asistente IA para Escuela de Ajedrez

## Objetivo General
Desarrollar un sistema web Helpdesk con asistencia de Inteligencia Artificial para registrar, clasificar y agilizar la atención de consultas técnicas, administrativas y pedagógicas (reglamento, torneos y estudio de aperturas) en una escuela de ajedrez.

## Objetivos Específicos
1. Diseñar e implementar una base de datos en MongoDB Atlas para almacenar usuarios (alumnos e instructores), tickets de consulta e historial de interacciones con el asistente.
2. Desarrollar el servidor backend en Node.js y Express para gestionar el registro, categorización y seguimiento de cada solicitud.
3. Integrar un asistente inteligente que brinde respuestas iniciales automatizadas sobre dudas de ajedrez y soporte antes de escalar el caso a un instructor.
