# Sistema Web Helpdesk con Asistente IA

## Objetivo General
Desarrollar un sistema web Helpdesk con asistencia de Inteligencia Artificial para registrar, clasificar y agilizar la atención de consultas e incidencias técnicas en una institución educativa.

## Objetivos Específicos
1. Diseñar e implementar una base de datos en MongoDB Atlas para almacenar usuarios, tickets de soporte e historial de consultas.
2. Desarrollar el servidor backend en Node.js y Express para gestionar el registro y seguimiento de cada solicitud.
3. Integrar un asistente inteligente que brinde respuestas iniciales automatizadas antes de escalar el caso a un encargado.
